# Design reference mockups

These are the approved visual designs, drawn at a 1440 × 900 desktop frame (Mobile is 390 × 844).
They were built in a design tool and need its runtime script, which isn't included, so they won't open correctly in a browser.
Read the markup instead: the inline styles give exact positions, sizes, colours and copy.
